# Brightbound — тестовый клиент

Самостоятельный прототип: ручная стрельба, гравитационный захват и бросок,
рикошеты, физические объекты, соло и кооператив на 2–4 игроков.

Версия 0.4.0: большая поляна, мини-карта, волны мобов каждые 20 секунд,
база лечения и пополнения патронов. Прицел убран. Добыча подбирается автоматически:
аптечки, патроны, дробовик, искромёт, перегрузка на 12 секунд и детали.
R переключает найденное оружие. Стартовая «Искра» не требует патронов;
20 деталей дают +10 максимального здоровья. База выдаёт +30 здоровья и
+60 патронов раз в 20 секунд каждому участнику.

Скачайте **Brightbound-Client-0.4.0.zip** из Releases, распакуйте целиком и запустите
**BrightboundLauncher.exe**. В лаунчере доступны «Играть» и «Обновить».
Новые версии игры устанавливаются отдельно; предыдущая версия сохраняется.
Редактор Godot и дополнительные платные программы для запуска не нужны.

Управление: WASD — движение, мышь — камера/прицел, ЛКМ — выстрел,
ПКМ удерживать — захват, отпустить — бросок, Q — импульс,
Пробел — прыжок, Shift — рывок, R — смена оружия, Esc — пауза.

Для теста на выделенном сервере нажмите «Подключиться к серверу / хосту»:
адрес **72.56.40.234** уже указан, порт **UDP 24680**. Забег запускается
автоматически; можно подключить до четырёх игроков. После завершения сервер
готовит следующий раунд. Домашний проброс портов для этого режима не нужен.

Также можно создать комнату на своём ПК: друг вводит IP хоста. Для подключения
к домашнему хосту через интернет нужен публичный IP и проброс UDP 24680.
В обычной комнате улучшения выбирает хост; на выделенном сервере выбор автоматический.

Для слабой видеокарты включите «Упрощённая графика» в лаунчере.
Минимальные требования будут уточняться по тестам на разных компьютерах.
